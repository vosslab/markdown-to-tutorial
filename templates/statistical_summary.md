## Tutorial

### Part: Describe the data

- **Worksheet:** Measurements

State what students should notice before calculating a summary statistic.

#### Step: Calculate a mean

1. In cell D1, type [Statistic](label:D1), and in cell E1, type [Value](label:E1).
2. In cell D2, type [Mean response](label:D2).
3. In cell E2, enter [`=AVERAGE(B2:B5)`](enter:E2).

Explain the units and ask students to interpret the result in the context of the experiment.

#### Step: Record a conclusion

In the response area, ask a question that requires students to use the calculated value and the
biological context. Keep the response cells blank in the starting workbook.
