## Tutorial

### Part: Organize an ANOVA table

- **Worksheet:** ANOVA

Explain why ANOVA compares variation among group means with variation within groups.

#### Step: Build the table students will use

1. In cell E1, type [Source of variation](label:E1).
2. In cell F1, type [Degrees of freedom](label:F1).
3. In cell G1, type [Sum of squares](label:G1).
4. In cell H1, type [Mean square](label:H1).
5. In cell I1, type [F statistic](label:I1).
6. In cell E2, type [Between groups](label:E2).
7. In cell E3, type [Within groups](label:E3).
8. In cell E4, type [Total](label:E4).

Explain why each row belongs in the table before asking students to calculate it.

#### Step: Calculate a group summary

1. In cell E6, type [Control mean](label:E6).
2. In cell F6, enter [`=AVERAGE(A2:A4)`](enter:F6).

Ask students to extend the table for the remaining groups using ordinary spreadsheet formulas.
Keep calculations and interpretation responses blank in the starting workbook.
