# Student README onboarding

The README now starts with a reading path for BIOL 318 tutorial authors: see the formatting guide,
copy a small labeled example, consult the authoring guide, then build and check the lesson.
Readers using an assigned tutorial are directed to its supplied document and workbook.

Existing screenshots and their managed block are unchanged. Detailed Caffeine and complete-source
examples remain available in a disclosure, alongside an optional worksheet-edit preview.
The build path uses the labeled formatting demo and explains the resulting files.
